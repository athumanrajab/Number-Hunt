# Number Hunt

Number Hunt is a number guessing game built with HTML, CSS, and vanilla JavaScript. Players try to guess a randomly generated number between 1 and 20 while managing their score and trying to achieve the highest possible score.

## Features

* Random number generation
* Number guessing between 1 and 20
* Score tracking
* Highscore tracking
* Feedback based on the player's guess
* Attempts decrease the player's score
* New game functionality
* Interactive user interface
* Input validation

```text
Number-Hunt/

```

## Run Locally

Install [Node.js](https://nodejs.org/) and `live-server` globally before running the project:

```bash
npm install -g live-server
```

Clone the repository, enter the project directory, and start the local server:

```bash
git clone https://github.com/athumanrajab/Number-Hunt.git
cd Number-Hunt
live-server
```

Then open:

```text
http://127.0.0.1:8080
```

## How to Play

1. Start the game with the hidden number displayed as `?`.
2. Enter a number between **1 and 20**.
3. Click **Check!** to submit your guess.
4. The game tells you whether your guess is too high, too low, or correct.
5. Your score decreases with each incorrect guess.
6. Try to guess the number before your score reaches zero.
7. Your highest score is saved as the highscore.
8. Click **Again!** to start a new game.
